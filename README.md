# Minecraft 模组自动汉化工具（完全免费）

自动汉化 Minecraft 模组，使用**完全免费的翻译接口**，无需付费。  
支持 DeepSeek、Google 翻译、LibreTranslate、MyMemory，自动故障转移。

## ✨ 特性
- 纯终端运行，一键汉化所有模组
- 精确保护占位符（`%s`、`{0}`、颜色代码等）
- 重新打包模组，输出到独立文件夹，原文件不变
- 多引擎自动切换，保证可用性
- **单文件运行**：只需下载 `auto_localizer.py`，首次运行自动配置
- 本程序由Deep Seek生成
